What it is

A minimal, capability-based microkernel written from scratch in C for beagle bone black board having ARMv7A architecture. Unlike monolithic kernels where device drivers, file systems, and network stacks share supervisor mode with the kernel, this architecture enforces the principle of least privilege. Only thread scheduling, low-level IPC, and memory space mapping execute in privileged mode. Everything else runs as isolated user-space services.

Core Architecture & Goals

  • Minimal Privileged Core: Keeping the trusted computing base under 10,000 lines of verifiable C to eliminate whole classes of privilege escalation bugs.
  • Synchronous & Fast-Path IPC: Implementing register-based and shared-page message passing primitives with low overhead.
  • Capability-Based Security: Every system resource (threads, memory frames, communication channels) is governed by unforgeable capability tokens.
  • Address Space Isolation: Enforcing strict hardware memory boundaries so that a crash in a device driver cannot compromise the kernel or other user-space processes.
  • User-Space Device Drivers: Handling interrupts and device memory via mapped I/O pages and user-level interrupt service threads.
  • Fault handling: Checking for faults and recovering from errors in a controlled manner.
